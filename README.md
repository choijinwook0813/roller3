# 중형 롤러 #3 생산 불량 관리 (개인용)

폰으로 식별표 불량을 기록하고, 주야 생산량을 입력해 월별로 정리하는 웹앱입니다.
서버, 로그인, 외부 CDN이 필요 없습니다. 데이터는 **이 기기 브라우저의 localStorage**에만 저장됩니다.

## 화면 (상단 월 선택 ◀ ▶ 기준, 하단 탭 4개 / PC는 왼쪽 메뉴)
| 탭 | 내용 |
|---|---|
| 기록 | 식별표 1장 = 1건. 날짜(‹ › 로 하루씩 이동, 날짜를 누르면 달력, [오늘로 돌아가기]) · 주/야 · 공정(황삭·중삭·단면·사상·S/F·기타) → 사유 버튼 → 수량(+100/+500/+1000) → 리워크(주황)/불량(빨강) 자동 분류 → [저장 후 다음 식별표]. 아래에 고른 날짜의 식별표 목록(누르면 수정·삭제) |
| 생산량 | 그 달 날짜별 주간/야간 생산량 바로 입력 (미입력은 회색, 휴무는 0 입력, Enter로 다음 칸) |
| 월별 현황 | 요약 카드(전월 대비) · 일별 표(일계/주간/야간/전체, 날짜 누르면 식별표 펼침, ⚠ 생산량 누락) · 공정별/사유별 막대 · 일별 불량률 추이(주간·야간) · 최근 12개월 |
| 설정 | CSV 내보내기 2종(일별 현황표, 식별표 원본) + 공유/저장/엑셀용 복사 · 전체 백업/복원(JSON) · 분류 규칙 |

## 계산
- 총 생산량 = 주간 + 야간, 양품 = 총 생산량 − 불량 (리워크는 양품에 포함)
- 양품률·불량률·리워크율 = ÷ 총 생산량, 소수점 2자리 %, 생산량 0이면 "-"
- 식별표는 적힌 날짜·주야 기준으로 집계

## 분류 규칙 (기본값, 설정에서 수정)
- 리워크: 황삭·중삭·사상 `드레싱 초품` / S/F `품질세팅품 진원도NG 크라우닝NG 상호차NG 테이퍼NG 외관NG`
- 불량: 황삭·중삭·사상 `외관NG` / 단면 `R값NG 과연삭 품질세팅품 흑피 외관NG` / S/F `조도NG 미S/F` / 기타 `낙추품 충돌품` (충돌품·낙추품은 기타 공정에만 있음)
- [직접 입력]한 사유는 리워크/불량을 고르면 그 공정의 사유 버튼으로 추가되고 다음부터 자동 분류됩니다.
- 규칙을 바꾸면 기존 식별표에도 적용할지 묻습니다.

## 설치 (홈 화면에 추가, 오프라인)
HTTPS 주소에서 열어야 합니다. 이 폴더를 그대로 GitHub Pages 등 HTTPS 호스팅에 올린 뒤,
- 안드로이드: Chrome 메뉴 → 홈 화면에 추가 / 앱 설치
- 아이폰: Safari 공유 → 홈 화면에 추가

처음 열면 빈 상태로 시작합니다.

## 데이터 보관
- 브라우저 데이터 삭제 / 시크릿 모드 / 다른 브라우저에서는 기록이 보이지 않습니다.
- 마지막 백업 후 7일이 지나면 상단에 알림이 뜹니다. **설정 → 백업 공유**로 카톡(나에게)·메일에 보관하세요.
- 아이폰은 홈 화면 앱과 Safari의 저장소가 따로입니다. 한쪽만 쓰세요.

## 파일
```
index.html  style.css  manifest.webmanifest  sw.js  icons/
js/core.js      공정·사유·분류 기본값, 저장소, 집계
js/ui.js        토스트, 시트, SVG 그래프, 공유/저장/복사
js/record.js    기록      js/prod.js   생산량
js/month.js     월별 현황  js/settings.js 설정·CSV·백업
js/app.js       월 선택·탭·알림
```
앱 파일을 고친 뒤에는 `sw.js`의 `CACHE = 'r3-v4'` 버전을 올려야 설치된 폰에 반영됩니다.
